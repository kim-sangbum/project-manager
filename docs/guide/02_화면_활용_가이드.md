# 2. 화면 활용 가이드

상단 메뉴는 **📊 대시보드 · 🏢 그룹보드 · ⚙️ 기준정보 · 🗺️ 로드맵 · 📖 가이드** 다섯 가지예요. 🗺️ 로드맵은 앞으로 만들 AX 전주기 플랫폼의 청사진이에요.

---

## 상단 통합 설정창

대시보드 맨 위의 **설정**을 펼치면 조건을 바꿀 수 있어요. 한 줄에 4칸씩 같은 너비로 놓여 있고, 각 항목 옆 **ⓘ** 에 마우스를 올리면 설명이 나와요. 오른쪽 위 **설정 고정**을 켜면 설정창이 늘 펼쳐져 있어요.

### A. 공통 조건 — 대시보드 전체에 적용

| 항목 | 설명 |
|---|---|
| **POR 연도** | 기준 스냅샷 연도. REF의 "POR (AX 없음)"이 이 연도예요 |
| **현재 연도** | 실적 구간의 마지막 연도. 이후는 예측 구간이에요 |
| **직군** | 전체 / 공정 / 설비. 고르면 네 섹션을 모두 그 직군으로 다시 계산해요 |
| **그룹 선택 · 파트 선택** | 보고 싶은 범위. 소속은 **그해 인원 시트 기준**이라 그룹을 옮긴 파트는 옮긴 해부터 새 그룹에 들어가요(차트에 '↔ 그룹 이동' 표시). 파트 목록은 적용된 직군·그룹에 한 해라도 속했던 파트예요 |
| **REF (기준)** | KPI 변화량(Δ)과 FTE 브리지의 시작점 |
| **COMPARE (비교)** | KPI 값, FTE 브리지의 도착점, AX 효과·파트별 결과 표의 기준 시점. 목표 = 예측, 실적 = 실제 효과 |
| **계획 묶음 반영 (COMPARE)** | 없음 / 계획대로. 계획대로 = 조직변경 시트의 '계획' 파트 묶음까지 반영('실적' 묶음은 늘 반영). 파트 신설·폐지·그룹 이동은 이 선택과 상관없이 그해 인원 시트 명단대로 반영돼요 |
| **이슈 대비** | 연평균 / 최대 이슈 1건 / 동시 2건 (3장 참고) |
| **계산 옵션** | **인원 변동** = 연도별 인원 스냅샷의 총원 사용(끄면 POR 총원 고정) · **교차 숙련** = 묶음 근무대마다 파트별 최소 1명 |
| **미래 빈도** | 증감 예측 반영(현재 연도 이후는 그해 빈도 또는 회귀 예측) / 현재 빈도 유지 |

### B. 차트 설정 — 표현 방식

| 항목 | 설명 |
|---|---|
| **차트 시작 · 끝** | 차트에 보여 줄 연도 범위. 기본은 REF ~ REF + 4년 |
| **인당 관리 지표** | 챔버 / 설비 |
| **추이 단위** | FTE / 공수(연간 업무시간) |
| **업무량 차트** | 누적 막대 / 누적 비율 / 라인 |

### [✅ 설정 적용] 버튼

값을 바꾸기만 해서는 화면이 바뀌지 않아요. **[✅ 설정 적용]**을 눌러야 한 번에 반영돼요. 누르면 다음 순서로 다시 계산해요.

1. 연도(POR·현재 연도) → 시뮬레이션 조건 → 차트 범위를 반영해요.
2. 미래 연도의 **(회귀) 빈도**를 다시 계산해요. 현재 연도 −2년 ~ 현재 연도의 (입력) 빈도로 파트 × 소분류마다 1차 직선을 그어 미래 빈도를 예측해요(음수는 0).
3. 대시보드 전체를 다시 계산하고, 위에 "설정을 적용했어요"라는 안내를 띄워요.

## 대시보드 4대 섹션 읽는 법

### 1. KPI 요약

카드 5개가 있어요: **팀 전체 · 공정 오피스 · 공정 교대 · 설비 오피스 · 설비 교대**.

- 큰 숫자 = REF 대비 **FTE 확보 변화량**(Δ = COMPARE − REF). 블루는 늘어남, 레드는 줄어듦(오른쪽 위 배지 ▲ / ▼)
- 막대 두 줄 = COMPARE(위)와 REF(아래)의 FTE 확보 크기
- 아래 작은 글씨 = COMPARE·REF 값과 **업무공수**(연간 업무시간 = 빈도 × 건당 시간 × (1 − 자동화율))와 그 변화
- 범위에 해당 직군·근무형태가 없으면 "해당 없음"으로 보여요

### 2. 인적자원

한 줄에 차트 4개가 있어요.

| 차트 | 읽는 법 |
|---|---|
| **인력 · FTE 종합 현황** | 연도별 필요 인원(회색)과 FTE 확보(블루), 재배치 대상(레드). 막대 위 숫자 = 총원 |
| **연도별 FTE 확보 추이** | 실적 막대 + 목표 선. 점선은 '목표 + 계획 묶음' |
| **FTE 브리지 (REF → COMPARE)** | REF에서 COMPARE까지 FTE 확보가 어떤 이유로 변했는지 계단식으로 보여요. 블루 = 늘어남, 레드 = 줄어듦. 순서: REF → 인원 변동 → AX 효과 → 묶음 효과 → 조직 변경 → 재배치 대상 제외 → COMPARE. 단계를 모두 더하면 정확히 COMPARE 값이 돼요 |
| **근무형태별 FTE 확보** | 교대·오피스로 나눈 FTE 확보. 위 숫자 = 합계 |

그 아래 **[파트별 결과 · 그룹보드에서 보기 · 묶음 상세]** 펼침을 열면 표와 버튼이 나와요(대시보드는 차트 위주라 기본은 접혀 있어요). **파트별 결과 표**는 COMPARE 시점의 파트별 총원, 필요 인원, 교대·오피스 확보, 근무대별 자리(현재 → 필요)를 보여요. **상태** 열은 🔵 여유(+0.1명 넘게 남음) / ⚪ 적정(±0.1) / 🔴 부족이에요. 파트를 고르고 **[그룹보드에서 보기]**를 누르면 그룹보드의 해당 파트 상세로 이동해요. 같은 펼침 아래쪽에 **조직개편(묶음) 상세**(묶음별 단독 필요 → 묶음 필요, 최소 인원 등에 걸린 근무대)가 있어요.

### 3. 업무량

| 차트 | 읽는 법 |
|---|---|
| **인당 관리 챔버 / 설비 수** | 공정·설비를 나눠 실적 막대와 목표 선으로 보여요. 높을수록 1명이 맡는 설비가 많아요 |
| **이벤트 · 루틴 · 이슈 업무 빈도** | 대분류별 연간 건수. **누적 막대**는 현재 연도까지 진하게, 이후는 흐리게 그리고, 실선 '실적 합계'와 점선 '예측 추세선'(1차 회귀)을 함께 보여요. **누적 비율**은 대분류 비중, **라인**은 실적 실선 · 예측 점선이에요 |

### 4. AX 효과 (COMPARE 기준)

- **대분류별 절감 공수 (1행 4열)**: KPI 카드와 같은 순서로 **공정 오피스 · 공정 교대 · 설비 오피스 · 설비 교대** 차트가 하나씩 있어요(설정에서 직군을 고르면 그 직군의 오피스 · 교대 2개). 축은 대분류이고, 막대 = COMPARE 시점의 POR 대비 절감 공수(옆에 시간과 절감률), **| 표시 = 목표 절감 공수**(POR × 목표 자동화율)예요. **막대 색 = 달성 상태**(COMPARE가 실적일 때): 블루 = 실적 ≥ 목표 · 그레이 = 목표의 80% 이상 · 레드 = 그 밖(미달·지연) · 연회색 = 목표 없음 · 빗금 연회색 = 미보고. COMPARE가 목표면 모두 연한 블루(예측)예요. 범례는 네 차트 위에 한 번만 보여요. COMPARE가 '목표'면 막대 끝과 | 가 같고, '실적'이면 실적이 목표에 얼마나 못 미치는지(넘는지) 보여요. 네 차트는 X축 눈금이 같아서 크기를 바로 비교할 수 있어요.
- **[소분류별 AX 요약]** 펼침 (기본은 접힘): **직군 · 근무형태(교대 / 오피스, KPI 카드와 같은 기준 — 오피스만 있는 파트는 교대 업무도 오피스)** · 소분류마다 기준 공수, 잔여 공수, 절감 공수, 목표·실적 자동화율, 달성 상태(🔵 실적 ≥ 목표 · ⚪ 목표의 80% 이상 · 🔴 그 밖 · — 목표 없음 · 미보고)를 보여요. 잔여·절감 공수는 KPI와 같은 기준(기준 공수 × (1 − 자동화율))이고, COMPARE가 실적이면 조사한 업무의 **(실측) 잔여 공수**를 참고 열로 함께 보여요(계산에 반영하려면 기준정보 › 실적 보정).
- **실적 보고율** (COMPARE가 실적일 때): 목표가 있는 업무 중 그해 실적을 보고한 비율을 파트별로 보여요. 미보고 업무는 직전 연도 보고 실적을 이어받아요.

## 그룹보드 활용법

그룹보드 위쪽 설정창은 연도·시뮬레이션 조건만 있어요(대시보드와 같은 값을 써요).

### 파트 부하 진단 (버블 차트)

| 축 | 뜻 |
|---|---|
| **X축** | 인당 챔버 = 챔버 수 ÷ 총원 |
| **Y축** | 부하율 = 필요 인원 ÷ 총원 (기준을 바꾸면 업무시간 ÷ 가용시간) |
| **버블 크기** | 총원 |

- Y = 100% 점선 위쪽은 지금 인원보다 일이 많은 영역이에요. **110% 초과 = 부족**(OT로 버티는 중), **90% 미만 = 여유**, 그 사이는 적정이에요.
- 위쪽 스위치로 **보기**(그룹 / 파트 색), **직군**, **부하율 기준**을 바꿀 수 있어요.

### 파트 분석 (3단계 근거)

버블을 누르거나 아래 **파트 분석**에서 파트를 고르면 "왜 부족 / 여유인가"를 3단계로 보여 줘요.

1. **요약 진단** — 총 부하율, 교대·오피스 FTE 여유/부족, OT로 버티는 인원(추정), 업무 TYPE별(이벤트·루틴·이슈·비가동) 시간 비중
2. **설비 부하 근거** — 인당 관리 챔버 수를 다른 파트와 비교
3. **업무별 근거** — 대분류별 소요시간(POR vs COMPARE). 시간이 가장 많이 드는 병목 3개를 강조해요

### 그룹별 상세

그룹을 여러 개 골라(전체 선택 / 지우기 버튼) 그룹마다 지표, 파트 표, 대분류 × 파트 AX 막대, 파트별 근무대 자리와 AX 내역을 펼쳐 볼 수 있어요.

## 기준정보 화면 (간단히)

엑셀 5개 시트와 같은 탭이 있어요. 표는 기본으로 잠겨 있고, **✏️ 데이터 수정**을 눌러야 고칠 수 있어요(한 번에 표 하나만). 저장할 때 입력 검사를 해서 잘못된 행 번호를 알려 줘요. 회색 열은 자동으로 채워지는 값이라 고칠 수 없어요. 자세한 입력 방법은 4장을 보세요.
