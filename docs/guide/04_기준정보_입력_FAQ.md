# 4. 기준정보 입력 & FAQ

기준정보는 **엑셀 파일 하나**(시트 5개)로 주고받아요. 화면의 ⚙️ 기준정보에서 바로 고치거나, 엑셀로 내보내 고친 뒤 다시 가져올 수 있어요. 회색 열(대분류~TYPE, (실측) 자동화율, 입력 안내, 상태, 입력 검사)은 자동으로 채워지니 비워 두세요.

---

## 엑셀 기준정보 5대 시트 작성 가이드

### ① 업무구분 — 업무 체계와 공통 AX 목표

| 열 | 입력 요령 |
|---|---|
| 코드 · 직군 | 소분류 고유 코드(예: `E-EV-003`)와 공정 / 설비 / 공통 |
| 대분류 · 중분류 · 소분류명 | 업무 체계. 계산은 소분류 단위로 해요 |
| TYPE | 이벤트 · 루틴 · 이슈 · 비가동 |
| 비가동 종류 | 비가동만: **근무 중**(식사·휴식) / **근무 외**(연차·교육) |
| 수행 위치 | 오피스 / 교대 / DAY / SWING / GY |
| 라인 내 물리 업무 | 사람이 라인에 꼭 가야 하는 일이면 표시 → 그 근무대에 최소 1자리 |
| 연기 가능 | 이슈 날 미룰 수 있는 루틴이면 표시 |
| 묶을 때 방식 | 합산(파트마다 따로) / 1회만(묶이면 한 번만) |
| **"2027 목표"** 같은 연도 열 | 그해 **공통 AX 목표 자동화율**. 연도는 계속 늘릴 수 있어요 |

### ② 파트별 업무·실적 — 파트가 하는 일의 양 (연도별 스냅샷)

한 줄 = **연도 + 파트 + 코드**.

| 열 | 입력 요령 |
|---|---|
| (입력) 빈도 · 빈도 단위 | 그해 몇 번 하는지 (하루 / 주 / 월 / 년). 미래 연도는 비워 두면 (회귀) 빈도로 예측해요 |
| (회귀) 빈도 | 자동 계산(설정 적용 때). 직접 고치지 않아요 |
| (입력) 건당 소요시간(분) | AX 적용 **전** 1건 처리 시간. 보통 POR 값을 그대로 이어 써요 |
| 파트 목표(%) | 이 파트만 공통 목표와 다르게 잡을 때 (그 줄의 연도에만 적용) |
| (실측) 빈도 · (실측) 건당 소요시간 | 실적 조사로 잰 값 (검수·실적 보정용) |
| (입력) 자동화율(%) | 파트가 보고한 **실적** 자동화율 (그 줄의 연도에만 적용) |

> 같은 업무를 **(입력) 열**은 계산용, **(실측) 열**은 조사 결과 확인용으로 나눠 둬요. 실측값은 계산에 바로 들어가지 않아요(FAQ Q3).

### ③ 조직변경 — 1행 = 1파트

| 열 | 입력 요령 |
|---|---|
| 연도 · 구분 | 언제, **계획** / **실적** |
| 변경 유형 | 파트 신설 · 파트 폐지 · 파트 병합 · 그룹 이동 · 파트 묶음 |
| 대상 파트 | 바뀌는 파트 **하나** (여러 파트를 묶으면 파트마다 한 줄씩) |
| 결과 (적용처) | 신설 = 배속 그룹, 병합 = 합쳐지는 파트, 그룹 이동 = 새 그룹, 묶음 = 묶음 이름(같은 이름끼리 한 묶음), 폐지 = 비워 둠 |

현재 연도가 지났는데 아직 '계획'인 행은 **⚠️ 미반영 계획**으로 표시돼요. 실제로 바뀌었으면 '실적'으로 바꿔 주세요(일괄 전환 버튼 있음).

### ④ 인원 — 연도별 스냅샷 (한 줄 = 연도 + 파트)

| 열 | 입력 요령 |
|---|---|
| SITE · 그룹 · 파트 · 직군 | 조직 정보 |
| 총원 | 그해 파트 인원 |
| (변동) 신입 · 전입 · 전출 · 퇴직 | 인원 변동 내역. 저장할 때 **전년 총원 + 신입 + 전입 − 전출 − 퇴직 = 총원**인지 검산해 경고해요 |
| 배치 DAY / SWING / GY | 지금 근무대마다 배치한 사람 수 (현재 교대 FTE 계산용) |
| **최소 DAY / SWING / GY** | 업무가 적어도 근무대에 꼭 있어야 하는 사람 수. 2인 근무가 필요한 근무대는 **2** |
| 교대 배분 DAY / SWING / GY | 수행 위치가 '교대'인 업무를 세 근무대에 나누는 비율 (합 100%) |
| 파트 ID · 전신 파트 ID · 참고 파트 | 신설 파트는 업무 데이터가 없으면 참고 파트의 업무를 챔버 수 비율로 키워서 써요 |

- 어떤 연도 스냅샷에 파트가 없으면 **폐지**로 보고 그 인원을 재배치 대상으로 계산해요(병합 행이 있으면 그 행의 연도부터 병합 — 재배치 대상에서 빠져요).
- 배치 자리를 채우는 데 드는 인원(자리 × 8h × 365 ÷ 1인 가용)이 총원보다 많으면 저장할 때 경고해요. 그러면 교대·오피스로 나눈 FTE 확보가 틀어져요.
- 그해 스냅샷이 아예 없으면 직전 연도 스냅샷을 써요.

### ⑤ 설비 — 파트별 장비 규모

| 열 | 입력 요령 |
|---|---|
| 파트 · 연도 | |
| 목표 / 실적 챔버 수 | 인당 관리 챔버 수, 부하 진단 X축, 신설 파트 업무량 비율에 써요 |
| 목표 / 실적 설비 수 | 인당 관리 설비 수에 써요 |

## 파트원이 흔히 하는 실수와 주의점

1. **건당 소요시간에 이동·대기 시간을 두 번 넣는 경우**
   라인까지 이동하는 시간을 모든 업무의 건당 시간에 조금씩 넣고, 별도 "이동" 업무로도 넣으면 같은 시간이 두 번 계산돼요. 한 곳에만 넣어 주세요.
2. **빈도 단위가 맞지 않는 경우**
   (입력) 빈도는 '주' 기준인데 실측은 '하루' 기준으로 적으면 7배 가까이 차이가 나요. (실측) 빈도도 **같은 줄의 빈도 단위**로 적어 주세요.
3. **분과 시간을 헷갈리는 경우**
   건당 소요시간은 **분** 단위예요. 1.5시간이면 90을 넣어요.
4. **AX 후 시간을 (입력) 건당 시간에 넣는 경우**
   (입력) 건당 시간은 AX **전** 시간이에요. 자동화로 줄어든 시간을 여기 넣으면 자동화율과 겹쳐서 두 번 줄어들어요. 줄어든 결과는 (실측) 건당 시간에 적고, 실적 보정으로 자동화율에 반영해요.
5. **큰 이슈를 한 건으로 넣는 경우**
   80시간짜리 사고는 "1건 × 80시간"이 아니라 하루 단위로 "5건 × 16시간"처럼 나눠 넣어요.
6. **여러 파트를 한 줄에 넣는 경우 (조직변경)**
   조직변경은 1행 1파트예요. A·B를 묶으면 두 줄에 같은 결과 이름을 넣어요.

## 자주 묻는 질문 (FAQ)

### Q1. 우리 파트 인원이 강제로 줄어드는 건가요?

아니에요. 이 시뮬레이터는 정원을 정하는 도구가 아니에요. AX로 반복 업무가 줄어든 만큼 **먼저 야근·과부하를 풀고**, 그러고도 남는 여력(FTE 확보)을 **신규 라인이나 바쁜 파트로 옮겨 배치할 수 있는지** 찾는 도구예요. 실제 배치는 사람이 결과를 보고 정해요.

### Q2. 업무량이 적은데 왜 필요 인원이 일정 수준 아래로 안 내려가나요?

교대는 근무대(DAY · SWING · GY)마다 **최소 인원**이 있기 때문이에요. 업무가 거의 없어도 인원 시트의 '최소 DAY / SWING / GY' 만큼은 자리를 채워야 하고, 자리 하나를 365일 채우려면 1명보다 많은 FTE가 필요해요.

> 예: 근무대마다 최소 2인(2 / 2 / 2 = 6자리), 연차·교육 연 200시간
> → 6 × 8 × 365 ÷ 1,880 ≈ **9.3 FTE**가 교대의 최저선이에요.

이 최저선을 낮추는 방법이 **파트 묶음**이에요. 묶인 파트끼리 근무대 자리를 같이 쓰면 최소 인원을 한 번만 채우면 돼요(3장 참고).

### Q3. 실적 조사를 하면 시뮬레이터에 어떻게 반영되나요?

조사한 값((실측) 빈도 · (실측) 건당 소요시간)은 **계산에 바로 들어가지 않아요.** 확인을 거쳐 반영해요.

1. 조사 결과를 파트별 업무·실적 시트의 **(실측)** 열에 넣어요. 회색 **(실측) 자동화율** = 1 − 실측 건당 ÷ 입력 건당이 자동으로 계산돼요.
2. 기준정보 › 파트별 업무·실적 › **실적 보정** 화면에서 입력값과 실측값 차이가 큰 줄을 확인해요.
3. 확인한 줄을 반영하면 (입력) 자동화율이 조사값으로 바뀌고 비고에 '조사 보정'이 남아요. 이때부터 '실적' 계산에 쓰여요.

조사 건당 시간이 오히려 늘었다면 자동화율을 0% 아래로 내리지 않고 **건당 시간 증가**로 따로 보여 줘요. 필요하면 같은 화면에서 (입력) 건당 시간을 실측값으로 고칠 수 있어요. 고치면 조사 연도와 **이후 연도** 줄(값이 같은 줄만)을 함께 고치고, 지난 연도는 그대로 둬요.

### Q4. 미래 연도 빈도는 어떻게 정해지나요?

미래 연도 줄의 (입력) 빈도를 비워 두면, [✅ 설정 적용]을 누를 때 **현재 연도 −2년 ~ 현재 연도** 실적 빈도로 직선 추세를 그어 (회귀) 빈도를 채워요. (입력) 빈도를 직접 넣으면 그 값이 우선이에요. 설정의 **미래 빈도 = 현재 빈도 유지**를 고르면 미래에도 현재 연도 빈도를 그대로 써요.
