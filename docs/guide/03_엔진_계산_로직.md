# 3. 엔진 계산 로직

계산은 **파트마다** 아래 5단계로 해요. 묶음이 있으면 묶인 파트를 하나로 합쳐 같은 단계를 거쳐요. 결과는 그룹 → SITE → 팀으로 더해요.

```
① 업무시간 연 환산   소분류마다  빈도 × 단위 환산 × 건당 시간
② AX 적용           × (1 − 자동화율)              ※ 비가동은 적용 안 함
③ 근무 위치 나누기   오피스 / DAY / SWING / GY
④ 필요 인원         교대 = 근무대 자리 → FTE,  오피스 = 업무시간 ÷ 가용시간
⑤ FTE 확보          (총원 − 재배치 대상) − 필요 인원
```

---

## ① 총 업무량 집계

소분류(업무) 하나하나의 연간 시간을 구해서 더해요.

```
연간 기준 공수 = 빈도 × 단위 환산 × 건당 소요시간(분) ÷ 60
```

| 빈도 단위 | 연 환산 |
|---|---|
| 하루 | 교대 업무 × 365 · 오피스 업무 × 260 (근무일) |
| 주 | × 52 |
| 월 | × 12 |
| 년 | × 1 |

- **빈도**: 그해 (입력) 빈도. 미래 연도라 비어 있으면 (회귀) 빈도(설정 적용 때 계산한 예측)를 써요.
- **건당 시간**: 그해 (입력) 건당 소요시간. 보통 POR 값을 그대로 이어 써요(AX 전 기준).

## ② AX 자동화 적용

```
잔여 공수 = 기준 공수 × (1 − 자동화율)
절감 공수 = 기준 공수 − 잔여 공수
```

자동화율은 시점에 따라 달라요.

| 시점 | 쓰는 자동화율 |
|---|---|
| POR (AX 없음) | 0% |
| 목표 | 파트별 목표(파트 목표 열, 그 행의 연도에만)가 있으면 그 값, 없으면 업무구분 시트의 그해 공통 목표. 그해 목표 열이 없으면 **가장 가까운 앞 연도 목표**를 이어서 써요 |
| 실적 | 파트별 보고 실적 ((입력) 자동화율). 그해 칸이 비어 있으면 **직전 연도 보고 실적**을 이어받고, 보고한 적이 없으면 0% |

- 이벤트 · 루틴 · 이슈에만 적용해요. 비가동(식사·휴식·연차·교육)에는 적용하지 않아요.

## ③ 근무 위치 분배

업무구분 시트의 **수행 위치**에 따라 나눠요.

| 수행 위치 | 나누는 방법 |
|---|---|
| 오피스 | 오피스 업무량에 더해요 |
| DAY / SWING / GY | 그 근무대에만 더해요 |
| 교대 | 인원 시트의 **교대 배분 DAY / SWING / GY** 비율로 세 근무대에 나눠요 |

교대 자리가 없는 파트(오피스만 있는 파트)는 교대 업무도 오피스로 계산해요.

## ④ 필요 인원 산출

### 교대 — 근무대마다 자리 수를 먼저 구해요

```
1자리 실근무 시간 = 8시간 − 근무 중 비가동(식사·휴식)
업무량 자리       = 근무대 하루 업무시간(연간 ÷ 365) ÷ 1자리 실근무 시간
하한             = 인원 시트의 '최소 DAY / SWING / GY'
                   (최소 인원이 0이어도 물리 업무가 남아 있으면 1)
필요 자리(근무대)  = 올림( max(업무량 자리, 이슈 날 자리, 하한) )
```

자리 1개를 1년 365일 채우려면 한 사람으로는 부족해요(사람은 연 2,080시간만 일하니까요). 그래서 자리를 FTE로 바꿔요.

```
1인 연간 가용시간 = 2,080 − 근무 외 비가동(연차·교육)
교대 필요 FTE    = (DAY + SWING + GY 필요 자리) × 8시간 × 365 ÷ 1인 연간 가용시간
```

> 예: 자리 1 / 1 / 2 = 4자리, 연차·교육 연 200시간 → 4 × 8 × 365 ÷ 1,880 = **6.2 FTE**

### 오피스 — 업무시간을 가용시간으로 나눠요 (올림 없음)

```
오피스 1인 연간 가용시간 = 2,080 − 근무 외 비가동 − 근무 중 비가동(연 환산)
오피스 필요 FTE          = max( 오피스 잔여 공수 ÷ 1인 연간 가용시간,  이슈 날 필요 )
```

### 합계

```
필요 인원 = 교대 필요 FTE + 오피스 필요 FTE
```

## ⑤ FTE 확보

```
FTE 확보     = (총원 − 재배치 대상) − 필요 인원
 ├ 교대 확보   = 현재 교대 FTE − 교대 필요 FTE
 └ 오피스 확보 = (총원 − 현재 교대 FTE) − 오피스 필요 FTE

현재 교대 FTE = 인원 시트의 '배치 DAY + SWING + GY' × 8시간 × 365 ÷ 1인 연간 가용시간
```

- **플러스** = 다른 업무·라인으로 옮겨 배치할 수 있는 여력
- **마이너스** = 지금 인원으로 부족(OT로 버티는 중)
- **재배치 대상** = 조직변경으로 폐지된 파트의 인원. FTE 확보와 따로 보여 줘요

## 파트 묶음(가상 조직개편) 시뮬레이션 원리

조직변경 시트에서 같은 **결과 (적용처)** 이름으로 '파트 묶음' 행을 넣은 파트들은 교대와 오피스를 **함께** 운영한다고 보고 한 덩어리로 계산해요.

| 항목 | 묶을 때 계산 |
|---|---|
| '합산' 업무 | 파트별 시간을 더해요 (각자 따로 해야 하는 일) |
| '1회만' 업무 | 가장 큰 파트 값 하나만 써요 (한 번 하면 모두에게 적용되는 일, 예: 공통 보고) |
| 하한(최소 인원) | 근무대마다 파트 최소 인원 중 가장 큰 값 |
| 이슈 대비 | 파트별 이슈 예비를 그대로 더해요 |

'합산 / 1회만'은 업무구분 시트의 **묶을 때 방식** 열로 정해요.

### 왜 줄어드나요? — 근무대 자리 공유

| GY 근무대 | 파트 A | 파트 B | 필요 자리 |
|---|---|---|---|
| 업무량 자리 | 0.6 | 0.7 | |
| 따로 운영 (최소 2인) | 2 | 2 | **4** |
| A + B 묶음 | 0.6 + 0.7 = 1.3 → 하한 2 | | **2** |

업무량이 적은데 최소 인원 때문에 자리를 지키던 파트들이 자리를 같이 쓰면, 업무는 그대로인데 자리가 줄어요.

- **교차 숙련 옵션을 켜면** 근무대마다 묶인 파트 수만큼은 자리가 있어야 해서(파트별 최소 1명) 묶음 효과가 작아져요.
- '실적' 묶음은 항상 반영하고, '계획' 묶음은 설정의 **계획 묶음 반영 = 계획대로**일 때만 반영해요.
- 파트 신설·폐지·그룹 이동은 이 설정과 상관없이 **그해 인원 시트 명단**대로 계산해요(조직변경 시트의 해당 행은 기록·검사용).
- 묶음은 자리·FTE를 줄이지만 업무공수(시간)는 파트별 값 그대로예요.

## 이슈 대비(Safety Margin) 인원

이슈(돌발 설비·품질 사고) 업무는 평소에는 연평균만큼만 들어가지만, 이슈가 터진 날에는 그날 일이 확 늘어요. 그날도 버틸 수 있도록 예비 자리를 둘지 정하는 설정이에요.

이슈는 **1건 = 이슈가 있는 하루의 추가 업무**로 입력해요(큰 사고 80시간이면 "5건 × 16시간"처럼 하루 단위로 나눠요).

| 수준 | 이슈 날 추가 업무 | 성격 |
|---|---|---|
| **Level 0 · 연평균** | 따로 점검하지 않아요 (연평균 이슈 시간만 평소 업무에 포함) | 가장 적게 잡음 |
| **Level 1 · 최대 이슈 1건** (기본) | 건당 시간이 가장 큰 이슈 1건 | 표준 |
| **Level 2 · 동시 2건** | 건당 시간이 가장 큰 이슈 2건의 합 | 가장 보수적 |

이슈 날 필요량은 이렇게 구해요.

```
이슈 날 업무 = 하루 이벤트 + 하루 필수 루틴(연기 가능 루틴 제외) + 이슈 추가 × (1 − 자동화율)
필요 자리(교대) = max(평시, 이슈 날)        ← 근무대마다
필요 FTE(오피스) = max(평시, 이슈 날)
```

연기 가능한 루틴은 이슈 날 다음으로 미룰 수 있다고 보고 빼요.

수행 위치가 '교대'인 이슈는 어느 근무대에서 터질지 모르니, 교대 배분 비율로 나누지 않고 **근무대마다 이슈 시간 전부**를 더해요(예: 4시간 이슈 → DAY·SWING·GY 각각 +4시간). 특정 근무대(DAY 등) 이슈는 그 근무대에만 더해요.
